# Merch Web: передача поддержки

Merch Web — внутренний сервис сверки работы мерчендайзеров микромаркетов:
выходы, поставки, инвент, кофемашина, возмещения, чеки и месячные отчёты.

Production: FirstVDS, [https://sverka-mm.ru](https://sverka-mm.ru).
Компоненты: FastAPI, PostgreSQL, Docker Compose и nginx с внешним HTTPS.
Сервисы Compose: `app`, `postgres`, `nginx`; `postgres-restore` используется
только для проверки восстановления.

Тесты из корня проекта в изолированном окружении:
`python -m pip install -r requirements.txt pytest httpx`, затем
`python -m pytest -q`, `python -m compileall -q app tests`, `python -m pip check`.
Не передавайте окружению тестов production-секреты.

Deploy выполняется по полному `TARGET_SHA` с проверкой образа, запущенного
контейнера и healthcheck; обновляется только `app`.
Команды deploy, backup, тестового восстановления и app-only rollback:
[VPS_RUNBOOK.md](VPS_RUNBOOK.md).

Для принятия поддержки внутренней команде необходимо получить:

- Доступ к GitHub, FirstVDS/SSH, домену/DNS и управлению TLS-сертификатами.
- Действующую конфигурацию площадки, Compose overrides, текущий SHA и проверенный
  образ для отката; подтвердить фактическую схему HTTPS на сервере.
- Секреты через корпоративное хранилище и ответственных за их ротацию.
- Доступ к резервным копиям, сведения о расписании/хранении и результат проверки
  восстановления, согласованные RPO/RTO и контакты дежурных.
- Подготовленную схему и обезличенные данные для локальной PostgreSQL, а также
  отдельное интеграционное окружение.
- Контакты владельцев бизнес-процессов, календаря и справочников; известные риски
  и задачи сопровождения через внутренний корпоративный трекер.

Состав репозитория и локальный запуск: [README](../README.md).
